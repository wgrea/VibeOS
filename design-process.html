✏️ Design Process & Architecture

Code-as-FigJam ➔ CSS Tokens ➔ HTMX State ➔ Three.js Demand Paging

🎨 Prototyping Workflow: Using Code Like FigJam

Instead of maintaining separate static canvases in traditional whiteboarding tools, VibeOS treats HTML, CSS, and static folders directly as a spatial FigJam board. Ideas start as raw semantic markup and lightweight staging files (aesthetics/staging.html), allowing layout constraints, token inheritance, and interactive states to be stress-tested immediately in the browser.

⚙️ Operating Systems & Computer Org/Design Aesthetics

1. Design Systems as a Mockup OS

Rather than treating aesthetics as a flat list of themes, VibeOS treats each visual family like a runtime environment with shared interaction primitives, state transitions, and token rules. Just as a low-level OS kernel manages hardware states, css/tokens.css acts as the central configuration registry. 

/* css/tokens.css */
:root {
  --neon-pink: #ff007f;
  --neon-cyan: #00f0ff;
  --bg-card: #181628;
  --border-outer: #2d284d;
  --radius-box: 16px;
}

2. Pre-Paging vs. Demand Paging

Core UI shells and tokens load upfront (pre-paging), while heavy Three.js scene factories and era assets hydrate only when a user selects a specific aesthetic pill (demand paging).

3. Interaction Kernel

A shared viewport controller (experience-viewer.js) manages input, spring physics, and camera state across every aesthetic without duplicating boilerplate.

🖥️ Core OS Systems & UI Translation

1. Window Lifecycle 🔄

  • Running (Focused): Active z-index layer, full bloom state.
  • Minimized (Waiting): Docked in taskbar with stashed coordinates.
  • Terminated (Closed): Unmounted from the DOM cleanly.

2. Inter-Process Communication (IPC) 📡

Modules communicate via custom DOM events and HTMX trigger pipelines, sending state focus updates between desktop widgets and taskbar indicators.

3. Directory Tree, Path Resolution & Debouncing 💾🚦

Structured hierarchy using relative paths (e.g. aesthetics/vaporwave-timeline.html or spiritual-skills.html) dynamically resolves sub-views without database overhead, while HTMX throttling (hx-trigger="click throttle:300ms") prevents UI race conditions during rapid user clicks.

📊 Pop vs. Non-Pop Aesthetics & Public Backlog

  • Aesthetic Cohesion vs. Subgenre Noise: A true aesthetic delivers a distinct sensory mood, color grammar, and tactile feel—whereas broad genres alone lack enough visual specificity to create an unmistakable "vibe."
  • Why the Backlog is Visible: Keeping the staging tracker open lets visitors and recruiters see the curation filter in action—how raw ideas are evaluated, grouped by schema, and graduated into interactive prototypes.

🚀 How VibeOS Stands Out from Guidebook Gallery

  • Interactive 3D Primitives over Static Moodboards: Instead of passive image galleries, every sub-aesthetic is expressed through live, draggable WebGL geometry, lighting, and spring physics.
  • Real-Time Parameterization: Studios like the Material & Garment Lab let users manipulate PBR roughness, clearcoat, silhouettes, and colors directly in the browser.
  • Systems-First Information Architecture: Built with static, zero-database HTML fragments (HTMX) and modular ES factories, proving clean frontend architecture alongside visual exploration.
